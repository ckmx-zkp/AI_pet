## 验收顺序

| 顺序 | 项 | 通过标准 | 失败时 |
|------|----|----------|--------|
| 1 | BOOT / 配网 | 能连自建 OTA，拿到激活或恢复会话 | 查 UART0 / Type-C 下载路径 |
| 2 | 眼睛五表情 | 语音或 MCP：neutral / happy / angry / sad / joy | 用 hwtest 的 `eye` 看 SPI 是否活 |
| 3 | 眨眼 / 闭眼 | `blink`、`close`、`open` 目视 | 查 `DualEyeDisplay` 资源 `.bin` |
| 4 | 灯带 | `set_emotion` 变色；`set_zodiac` 能换星座色 | hwtest `led`；确认 GPIO15 已拉高 |
| 5 | 拍照识图 | 「看看我」走 `take_photo`，服务端 M3 出中文描述 | 确认插的是 U4；对话 LLM 必须是 M2.5（M3 当对话会不调相机） |
| 6 | K230 | UART1 有 JSON；视线跟着偏 | 先 hwtest `k230` 发 PING |
| 7 | 舵机 | **硬件未接，本项跳过**；接上之前不改跟随、不为跟随去烧 | 方案见仓内 `AI_PET_FACE_FOLLOW_PLAN_zh.md`（Δx，禁止回中） |
| 8 | 喇叭 | TTS 听得见 | **先飞线 PA_EN 到 GPIO9 或 GPIO21**，原理图 GPIO46 软件拉不了 |

## hwtest 何时用

量产固件某项失败、怀疑是硬件时，再烧 `ai-pet-s3-hwtest`：

`i2c` / `eye` / `led` / `cam` / `k230` / `servo` / `pa`

不要在 hwtest 里做体验功能。
