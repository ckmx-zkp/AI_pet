# 冻结项与硬件门禁

未拍板或硬件未关之前，不要在这些方向开工，避免和并行会话抢契约。

## 跨仓冻结

| 项 | 原因 |
|----|------|
| E11 主动播报 | 语音 WS 轮询 vs 独立 MQTTS 未统一 |
| E9 BLE 偶遇双 AI | 包格式、双边同意、空闲控制通道未冻结 |
| S8 续聊提醒 | 仅有 90/240 秒设计 |
| 正式 HTTPS / WSS | 域名 + ICP 未做 |
| 把聊天 UI 画到眼珠 | S3 刻意 `NoDisplay` |
| 固件本地记忆库 | 与 Memory MCP 重复，S3 没余量 |

## 本板硬件门禁

| 门禁 | 事实 | 处理 |
|------|------|------|
| PA_EN = GPIO46 | S3 仅输入，R40 下拉，功放默认关 | 飞线或改版到 GPIO9 / GPIO21 后再验喇叭 |
| 4G UART 标 `1.8V?` | S3 是 3.3V | 未测通不要 `4gon` / 不要当常规项 |
| 4G 供电 | 联调记录 USB 无 +4V，AT 无回包 | P0–P2 不做 4G |
| USB 摄像头 | 接 U4（GPIO19/20） | 不要插 K230 Type-C；不要把 19/20 当 GPIO |
| 舵机 | 原理图只有 CN2 一路 PWM | 不要规划第二路舵机，除非改板 |
| 眼睛复位 | 与 ESP `EN` 短接 | 软件复位脚保持 NC |
