# 协作反馈日志（嵌入式会话）

> 给**下一个 Agent** 用：每次固件 / 大板调试收工后在本文**最上面**追加一条。  
> 本文件记**事实、缺口、建议下一步**；接口 schema 仍进各仓 docs，联调状态仍进 `work_dashboard`。  
> 密钥不写。看板仓脏时只读、不 pull、不混提交。

## 其他 Agent 开工怎么用

1. 先读 [[00-请先读我]] 和本页「当前建议下一步」。
2. 再读最新一条反馈（日期最大的那条）。
3. 对照 [[02-开发逻辑与阶段总表]] 的 P0→P4，不要跳去做冻结项（[[07-冻结项与硬件门禁]]）。
4. 动手前再核：`xiaozhi-esp32` 工作树、`AI_PET_PROGRESS_zh.md`、`work_dashboard/AI-Pet固件联调看板.md`（只读即可）。
5. 你做完后按文末模板再写一条，并改「当前建议下一步」。
