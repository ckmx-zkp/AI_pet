# AI玩具官方适配器件购买建议

依据：
- `AI玩具硬件电路确认表-0039.xlsx`
- `AI玩具样机功能拆分表-0627.xlsx`
- 本地 `xiaozhi-esp32` 官方仓库源码与 `main/idf_component.yml`

## 采购结论

首版样机优先购买官方仓库已经有成熟适配路径的器件：ESP32-S3R8N16 主控模组、ES8311 音频 Codec 方案、ST7789/GC9A01 屏幕、CST816S/CST816D/FT5x06/GT911 系列触摸、WS2812B 灯、ML307 Cat.1 模组。

K230、双 0.71 寸 TFT、底部压力、挂件状态、底座霍尔这些是本项目需求里的关键项，但不是小智官方默认完整闭环能力，建议按“接口预留 + 样机验证件”采购，不要一次性锁死大批量型号。

## P0 优先采购

| 类别 | 建议购买 | 官方适配依据 | 购买建议 |
|---|---|---|---|
| 主控 | ESP32-S3R8N16 或同级 ESP32-S3 N16R8 模组/开发板 | 小智大量板型以 ESP32-S3 为主，文档也指定 ESP32-S3R8N16 | 先买 2-3 块成熟 ESP32-S3 N16R8 开发板验证，再定自研板模组 |
| 音频 Codec | ES8311 + 单声道功放 + MEMS 麦 | 官方自定义板文档标注 ES8311 常用，多个板级代码使用 ES8311 | 优先买 ES8311 方案，少走音频驱动坑；功放可选 NS4150B/常见 Class-D |
| 麦克风 | I2S/PDM 数字 MEMS 麦，或 ES8311 对应模拟麦前端 | 官方有 ES8311、PDM、NoAudioCodec 路径 | 样机优先数字麦或成熟 ES8311 参考电路；结构上先保证声学开孔 |
| 眼睛屏幕 | 若坚持 0.71 寸，优先买 ST7789 SPI 屏并确认分辨率；同时备买 GC9A01 1.28 寸圆屏 | 官方通用 LCD 支持 ST7789 多分辨率、GC9A01 240x240；Spotpear 1.28 已适配 GC9A01 | 0.71 寸不是官方现成板型，先小批量买 4-6 片；1.28 GC9A01 可作为保底演示屏 |
| 触摸 | CST816S/CST816D、FT5x06、GT911 中优先 CST816 系列；4-6 区摸头可另购电容触摸按键/触摸电极方案 | 官方依赖和板级代码已有 CST816S/CST816D、FT5x06、GT911、CST9217 | 屏幕触摸买 CST816；毛绒多区域触摸不要用大屏触控方案，优先独立触摸电极/触摸 IC |
| 4G Cat.1 | ML307 成品模块，带天线/SIM 座/电源参考设计 | 官方依赖 `78/esp-ml307`，多个 ML307 板型已存在 | ML307 优先；Air780E 只买少量评估件，不作为首版默认 |
| 状态灯/氛围灯 | WS2812B 或兼容单总线 RGB 灯珠/灯环 | 官方 `led_strip`、`SingleLed`、`CircularStrip` 已适配 WS2812 | 买 WS2812B 2020/3535/5050 按结构选型；样机预留电流余量 |
| 底座识别 | Pogo Pin + 霍尔开关 + 小磁铁 | 文档 P0 要求底座/充电识别；官方侧可按 GPIO/ADC 状态接入 | 采购 Pogo 和霍尔是低风险方案，先别依赖复杂 IMU 判断底座 |

## P1 可买但控制数量

| 类别 | 建议购买 | 原因 |
|---|---|---|
| K230 视觉模块 | 买成品 K230 + 摄像头模块，要求 UART 可输出结构化识别结果 | 文档要求 P0，但小智官方仓库没有 K230 视觉完整适配；首版只接 event/bbox/confidence，不传图 |
| 压力传感 | FSR 薄膜压力片 + 分压电阻若干 | 文档 P1，用 ADC 很容易接入；但算法阈值需结构实测 |
| 挂件状态 | 霍尔/磁吸触点/滑动开关/拨码开关 | 比 IMU 更可控；用于区分挂包、底座、手持状态 |
| IMU | BMI270 或常见 I2C 六轴 IMU 少量评估 | 官方依赖里有 BMI270，但本项目文档只要求“预留低成本 IMU” |
| GNSS | 若必须户外定位，选择带 GNSS 的 Cat.1 模组评估件 | 文档默认可用网络位置/APP 城市；GNSS 不应进入首版硬性采购 |
| 舵机 | 仅买 1-2 套调试件 | 文档写“飞线连接”，官方有机器狗/舵机相关组件，但头部转动不是首版稳定闭环 |

## 暂缓或不建议首版采购

| 器件 | 原因 |
|---|---|
| Air780E 大批量 | 文档列为 ML307 备选，官方小智仓库里 ML307 路径更成熟；Air780E 要额外适配评估 |
| NFC 模组 | 文档明确 BLE 近场发现优先，NFC 不作为样机必选 |
| 复杂 16 点触摸方案 | 样机功能表只要求 4-6 区，复杂多点会拖慢结构和调试 |
| K230 高速 SPI/USB 图传链路配套件 | 首版明确 P0 不传图片流，只传结构化结果；保留焊盘即可 |
| 非 ST7789/GC9A01 的 0.71 寸未知驱动屏 | 驱动不确定会直接增加移植风险；除非供应商明确给出 ESP-IDF 驱动和初始化序列 |

## 关键采购约束

1. 0.71 寸 TFT 下单前必须确认驱动芯片、分辨率、SPI 模式、背光电流、FPC 间距和初始化代码。官方没有直接叫“0.71 寸”的板型，不能只按尺寸购买。
2. ML307 优先于 Air780E。Air780E 可以买评估件，但不要作为首版样机默认通信模块。
3. K230 只要求 UART 输出结构化识别结果即可，首版不要购买依赖高速图传链路的方案。
4. 触摸互动分两类：屏幕触摸可用 CST816 系列；毛绒外壳摸头/捏脸/抱抱应使用独立触摸电极或触摸 IC。
5. 底座/挂件识别优先用霍尔、触点、开关这类确定性器件，IMU 只做预留或辅助判断。
