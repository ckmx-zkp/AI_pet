# 部署与回滚手册

## 前置条件

- 服务器已有 Python 3.10+、Docker CLI 和 systemd。
- 本项目部署路径固定为 `/opt/ai-pet/ai-pet-ops`。
- 运行时配置为 `/etc/ai-pet-ops/services.json`；其中不应包含密钥。
- 本服务不开放端口、不创建反向代理、不改动现有 compose 服务。

## 首次部署（人工执行）

1. 将本仓部署到 `/opt/ai-pet/ai-pet-ops`。
2. 创建目录：`/etc/ai-pet-ops` 与 `/var/lib/ai-pet-ops`。
3. 从 `config/services.example.json` 复制出 `/etc/ai-pet-ops/services.json`，仅按已批准服务增删检查项。
4. 安装 `deploy/ai-pet-ops-collector.service` 和 `deploy/ai-pet-ops-collector.timer` 到 `/etc/systemd/system/`。
5. 依次执行 `systemctl daemon-reload`、手工启动一次 service、检查 `/var/lib/ai-pet-ops/status.json`，确认后启用 timer。

## 验收

- `systemctl status ai-pet-ops-collector.service` 显示最近一次执行成功。
- `systemctl list-timers ai-pet-ops-collector.timer` 显示下一次运行时间。
- JSON 快照可解析，包含全部白名单容器与 HTTP 检查项。
- 确认未开放新端口、未读取 `.env`、未修改或重启任何业务容器。

## 回滚

1. `systemctl disable --now ai-pet-ops-collector.timer`。
2. 删除已安装的 service/timer 单元并执行 `systemctl daemon-reload`。
3. 如不再保留历史快照，再人工删除 `/var/lib/ai-pet-ops`。

回滚不影响任何既有 Docker 容器、数据库或反向代理。
