# 监测指标与告警规范

## V0 采集项

| 分类 | 指标 | 判定 |
|---|---|---|
| 主机 | 根分区使用率 | >=80% 告警，>=90% 严重 |
| 主机 | 负载、内存、Swap | 记录快照，V0 不以单次值告警 |
| Docker | 预期容器运行状态 | 非运行或 OOM 为严重 |
| Docker | 重启次数、启动时间、健康状态 | 记录；health 未配置显式标记 |
| HTTP | backend、admin、app、xiaozhi loopback 探测 | 非预期状态码或超时为严重 |

## 状态与告警

- V0 只生成 JSON 快照和 systemd 失败状态，不向外部发送消息。
- V1 增加状态变化告警：连续两次失败才通知；恢复时发送一次恢复通知。
- 告警内容只包含服务名、状态、时间和诊断码；不带 URL 查询参数、响应体、环境变量或日志原文。
- 任何自动修复均不属于本项目 V0/V1 范围，必须经人工操作。

## 配置约束

- 运行时配置固定在 `/etc/ai-pet-ops/services.json`，由示例配置复制生成。
- URL 仅允许 `http://127.0.0.1` 或 `http://localhost`，避免采集器成为任意请求代理。
- 容器名称为显式白名单；新增业务容器需评审后写入配置。
